# Research and sources

Use the host's current web-research capability. The MCP server stores the result; it does not browse.

1. Define the topic, intended reader, time window, and decision or insight the post should support.
2. Prefer primary sources: official documentation, laws and policies, company announcements, original research, and first-party data.
3. Verify time-sensitive claims against current sources. Separate sourced facts from inference and opinion.
4. Keep the research notes concise but sufficient for another run to understand which claims the sources support.
5. Store only HTTP(S) source URLs used in the brief with `contentops_capture_research`.
6. Preserve citations during drafting when a claim benefits from verification.

Do not scrape LinkedIn pages or profiles. Do not use LinkedIn content as a source unless the user supplied it or it is available through an authorized, supported integration.
